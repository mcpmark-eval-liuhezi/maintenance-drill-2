# Maintenance Drill Notes

This repository is a disposable sandbox for rehearsing the quarterly maintenance loop before the maintenance window.

Scope of the drill:

- Manual-trigger workflow at `.github/workflows/drill.yml` that echoes a confirmation line.
- This short-lived branch (`drill/notes`) proposing a small documentation change as a draft pull request.
- A checklist issue with tracked sub-tasks.

No production repositories are touched; everything here is throwaway.
